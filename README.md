# Exploratory Data Analysis in Python

The EDA notebook for my capstone project in the Correlation data analyst fellowship.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/mohammad-qethama/eda_python/blob/master/eda.ipynb)

## What it does

- Loads the cleaned project dataset (`cleaned_data/total_eda.csv`)
- Generates a full automated profiling report (`report.html`): distributions, missing values, correlations and duplicate rows for every column
- Sets up pandas, NumPy, Matplotlib, Seaborn and Plotly for the follow-up analysis

The dataset itself is not included in this repo.

## Run it

Open the notebook in Colab with the badge above, upload `cleaned_data/total_eda.csv`, and run all cells.

## Stack

Python · pandas · NumPy · ydata-profiling · Matplotlib · Seaborn · Plotly
